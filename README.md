A small collection of projects I built to practise Golang (crafted by hand)

### expense-tracker

### github-activity 
Started Exploring Github Events API and parsed a subset of common events 
like PushEvent, PullRequestEvent, etc. and display most recent events 
given a github username of any user, tool is made for unauthenticated events only 
(Public) events No private events are shown.
